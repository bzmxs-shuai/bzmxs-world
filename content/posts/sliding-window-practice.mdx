滑动窗口适合处理连续子数组或子串问题。窗口的左右边界逐步移动，避免重复枚举每一个区间。

## 思路模板

1. 右指针扩展窗口。
2. 当窗口不满足条件时，移动左指针。
3. 在每一步更新答案。

```cpp
for (int r = 0; r < n; r++) {
  add(a[r]);
  while (!valid()) {
    remove(a[l]);
    l++;
  }
  updateAnswer();
}
```

练习时可以从最长不重复子串、最小覆盖区间、固定长度最大和这些题目开始。
