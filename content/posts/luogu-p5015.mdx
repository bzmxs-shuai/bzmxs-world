这道题要求统计标题中非空格字符的数量。重点是保留输入中的空格，所以读取时要使用整行输入。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
  string s;
  getline(cin, s);
  int ans = 0;
  for (char c : s) {
    if (c != ' ') ans++;
  }
  cout << ans << endl;
}
```

## 易错点

不要使用 `cin >> s`，它会在第一个空格处停止读取。
